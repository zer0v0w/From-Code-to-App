# Session 1 Fruit Bridge — Instructor Starter

This is the prepared bridge that lets students change one Dart value and see an already-running Flutter UI update without teaching the widget tree in Session 1.

## Use it

1. Create a starter project: `flutter create fruit_bridge`.
2. Replace `fruit_bridge/lib/main.dart` with this file's `main.dart`.
3. Run the app on the already-prepared target: `flutter run`.
4. Ask students to change `var fruit = 'apple';` to `var fruit = 'orange';`.
5. Save/use hot reload and observe the UI.

Keep the widget scaffold on screen but do not explain it yet. The learning focus is variables, strings, constants, running code, and cause/effect. In Chapter 2, revisit the same file and unpack `main`, `runApp`, `MaterialApp`, `Scaffold`, `Text`, `build`, `return`, and `const`.
