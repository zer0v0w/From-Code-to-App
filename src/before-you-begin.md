# Before You Begin

## Instructor preparation

Do not spend the first two hours installing tools. Before the first session, ask students to complete a setup check and provide a fallback for anyone whose device is not ready.

- Install Flutter using the [official installation guide](https://docs.flutter.dev/get-started/install).
- Run `flutter doctor` and resolve the required issues for the chosen target.
- Install/configure an editor with Dart and Flutter support.
- Create and run a sample Flutter project on an emulator, simulator, desktop, or physical device.
- Confirm that hot reload works in debug mode.
- Install Git and verify `git --version`.
- Provide a known-good starter repository or archive in case individual setup fails.

## Do not require every platform

For a beginner bootcamp, choose one supported target for the teaching environment. Android emulator/physical Android is a practical default for a mobile-focused course; adapt to the cohort's hardware and the instructor's setup. iOS builds require macOS and Xcode.

## Pre-course checklist

A student is ready when they can:

- Open the starter project.
- Run the app and see it on a device/emulator.
- Change a visible string and see it update after hot reload.
- Find the terminal and the `lib/` directory.
- Send the instructor a screenshot or short message confirming successful setup.

## If setup fails

Pair the student with the prepared device or starter environment. Do not make environment troubleshooting the hidden prerequisite for learning programming. Record unresolved setup issues and handle them outside the core lesson where possible.

Official resources: [Install Flutter](https://docs.flutter.dev/get-started/install), [Flutter learning pathway](https://docs.flutter.dev/learn/pathway/tutorial), [Hot reload](https://docs.flutter.dev/tools/hot-reload).
